# Matcha typography

User-supplied fonts by Khurasan, reviewed 2026-11-14.

- Matcha World: main page headings, world names, and display titles.
- Matcha Style: secondary headings, navigation, main actions, level numerals, coin balances, progress totals, and reward numbers.
- Satoshi remains the reading face for descriptions, settings, small labels, ratio denominators and detailed statistics. Timings and detailed numeric rows request tabular numerals for stable alignment.

Both installed packs explicitly allow personal and commercial use in their enclosed More Info.txt; preserved here as STYLE-LICENSE.txt and WORLD-LICENSE.txt. Matcha Squishy was reviewed but not installed because its supplied notice permits personal use only and directs commercial users to purchase a license.

Original OpenType files are served locally, with swap and Satoshi fallbacks. No synthetic bold or italic is applied to Matcha.
