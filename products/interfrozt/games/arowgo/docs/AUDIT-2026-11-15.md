# Game audit — 15 November 2026

## Scope

Local browser game: both forty-level campaign worlds, solver and session rules, saving/migration, currency and first-clear rewards, shop/profile persistence, tutorial flows, pointer and keyboard input, motion preferences, result screens and responsive navigation. Automated browser suites run in isolated contexts; the user's saved browser profile is not cleared.

## Findings and fixes

- The Cove home had a plain gradient after removal of the duplicated map. Added a dedicated generated tropical sea/sky background with palms framing the edges, retaining the separate transparent island hero and calm space for text.
- On a short phone, the home hero could shrink to about 34px tall. Reduced decorative header and shortcut spacing while preserving usable controls and verified the hero stays above 50px in the existing responsive check.
- Bloom's completion screen gained an extra world-transition button and overflowed on phones and landscape. Added compact spacing, a short transition label and an explicitly positioned landscape grid. Tested 320×568, 390×844, 844×390 and 1280×800.
- The Bloom finale inherited the Cove background once the next world unlocked. It now retains the Bloom theme.
- Home showed a world-specific title alongside whole-campaign totals, and called the forty-level completion a valley completion. Labels now say Adventure/Journey and Adventure complete.
- Profile storage errors were written into state but never displayed. Added a dismissible accessible alert. A storage-failure regression verifies that a failed gift save leaves the wallet unchanged and gift unclaimed, then succeeds exactly once when storage is restored.

## Test maintenance

The initial phone browser run had 44 passing and 5 failing tests. Two tests still visited the former single-world finale route; they now exercise `/finale/bloom`. The profile/shop test now opens the Edit profile tab and checks the current crate animation control. Result-motion testing now waits for the intentional fade to settle before asserting full opacity; it still checks final-arrow exit ordering and stable full-viewport bounds. Tests that bypass onboarding explicitly seed its completed flag before testing next-level navigation. No solver or reward assertion was relaxed.

## Limits

Automated passing checks do not establish absence of every possible bug. Physical Android/iOS devices, sound quality, screen readers and human difficulty calibration remain manual validation work. Production build reports the existing large Phaser bundle warning; this audit does not change the engine or split its bundle. Progress remains device-local, not account-synced.

Additional visual audit: large saved coin balances could push Settings outside a 320px viewport. Compact header spacing now preserves the full control row; the Cove home test checks every header item's horizontal bounds. This does not abbreviate or change wallet amounts.

The desktop Settings modal could grow below the viewport after the Time Boost controls were added. Its height is now bounded on all layouts, with internal scrolling for longer settings content. This restores access to Rule lab and Back to the puzzle without allowing the game page itself to scroll.

## Final browser verification

The complete suite ran all 100 desktop/phone cases: 96 passed in the initial full run. Follow-up isolated verification passed all six selected cases, covering every initial failure and both platforms. The failures were an unreachable desktop Settings action (fixed), the 15-skin reload test exceeding its 60-second budget under concurrent load (now given a scoped 120-second budget), and an old Bloom profile-total assertion (updated to 60/120 for the two-world campaign). All fifteen skin colors/effects and reduced motion remain asserted. The full Bloom and Cove campaigns, tutorials, reward persistence, save migration, profile editing, input, world navigation and responsive layouts were exercised.

A concurrent unit run hit two timing limits while browser work was running. The unit suite was rerun in isolation; its result is recorded below. These timing failures are retained here rather than presented as a clean first run.

Final isolated unit result: **169/169 passed across 22 files**. Final TypeScript check and production build: **passed**. Remaining build warning: large Phaser chunk, as noted above. No known failing automated case remains from this audit; physical-device and player validation limits still apply.
