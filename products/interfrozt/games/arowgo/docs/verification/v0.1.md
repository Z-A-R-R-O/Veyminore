# v0.1 verification — 10 November 2026

## Scope

Five-level browser prototype in the AROWGO package. Verification is package-local; no repository-wide or native-device pass is claimed.

## Automated evidence

- 49 unit/domain tests pass: original rules, arrow geometry, session validation, tools, all five complete solutions, isolated saves, first-clear reward idempotency and 125-coin campaign total.
- Browser coverage includes 34 cases across desktop Chromium and emulated phone contexts. Corrected cases were rerun after fixes rather than treating initial failures as passing.
- Full campaign journeys clear all five levels, unlock in sequence, reach 15 best stars/125 coins, and restore progress on reload.
- Practice stays reward-free and cannot unlock the next level. In-game motion preferences reach the hub Settings page. Browser Back restores the prior page.
- Existing gameplay coverage checks real pointer input, snake exits, curved collision recoil, exact heart accounting, rapid taps, restart cancellation, failed-attempt reload, Hint/Erase, Rule lab isolation, reduced motion and victory/retry presentation.
- Responsive checks cover 320×568, 375×667, 390×844, 412×915 and 844×390. Board, HUD, tool tray, mode action and Settings control fit inside the viewport. Main pages preserve bottom navigation. Settings content can scroll internally on short screens.
- TypeScript and production Vite build pass; Prettier check passes. Capacitor asset sync passes. The pre-existing large Phaser chunk warning remains; no bundle-size or frame-rate target is claimed.

## Visual review and fixes

Reviewed Home, Worlds, Progress, Settings, hint state and result captures. Removed a redundant Progress CTA that crowded small phones. Kept Rule lab in in-game Settings rather than the play header. Fixed desktop result overflow and the landscape Settings button's one-pixel overflow. Settings uses a bounded scroll area to keep every option reachable without moving the bottom navigation.
